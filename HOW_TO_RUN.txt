================================================================================
                    DeFi Risk Management Platform
                         HOW TO RUN LOCALLY
================================================================================

STEP 1: Navigate to Project
----------------------------
cd /workspace/app-adlvaxvg0we9


STEP 2: Install Dependencies
----------------------------
pnpm install

(This will take 2-3 minutes)


STEP 3: Start the Application
----------------------------
pnpm dev


STEP 4: Open in Browser
----------------------------
http://localhost:5173


STEP 5: Create Your Account
----------------------------
1. Click "Sign Up" tab
2. Enter username (e.g., john_doe)
3. Enter password (min 6 characters)
4. Click "Create Account"

⭐ First user becomes ADMIN automatically!


STEP 6: Explore Features
----------------------------
✅ View Dashboard
✅ Check Financial Weather
✅ Browse Vault Cards
✅ Click "Seed Demo Data" for sample transactions
✅ Toggle Dark Mode


OPTIONAL: Connect MetaMask Wallet
----------------------------
1. Install MetaMask from https://metamask.io/download/
2. Click "Connect Wallet" in app header
3. Approve connection
4. Switch to Sepolia testnet

================================================================================
                         TROUBLESHOOTING
================================================================================

Problem: "pnpm: command not found"
Solution: npm install -g pnpm

Problem: "Port 5173 already in use"
Solution: lsof -ti:5173 | xargs kill -9

Problem: "MetaMask is not installed"
Solution: App works without MetaMask! Install only if you want Web3 features.

Problem: Dependencies not installing
Solution: rm -rf node_modules && pnpm install
